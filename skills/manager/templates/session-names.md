# Session and agent names

- Pattern: `<area>-<task>` in kebab case, under 30 characters: `api-paging`, `web-checkout-fix`, `infra-ci-cache`.
- Roles: `manager`, `state`, `bugfix`, `review-<area>`, `docs`.
- Finished: rename to `Done: <name>` and tell the state owner.
- Blocked for a human: prefix `Wait: <name>`.
- Never put customer, company or personal names in session names that other people will see.
