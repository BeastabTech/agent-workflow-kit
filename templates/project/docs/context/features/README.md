# Feature files

One file per feature: purpose, flow, endpoints or screens, flags, permissions, open questions. Later sections override earlier ones; mark replaced text **Outdated**.

Template:

```markdown
# <Feature>
- Owner: <human owner>
- Status: planned | building | live | outdated
- Flag: <ENV_FLAG> (default off)

## Flow
## API / screens
## Data
## Open questions
- @question ... (asked <date>)
## Changelog
- <date>: <change>
```
