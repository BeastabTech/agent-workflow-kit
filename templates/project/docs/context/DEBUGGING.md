# Debugging notes

Add a section whenever you debug something non-obvious. Format: **symptom → cause → how to check** (exact commands, read-only first). Never paste secrets, tokens or personal data.

## Template

### <symptom as a user or log would describe it> (<date>)
- Cause: <root cause>
- Check: `<read-only command>` → <what a healthy result looks like>
- Fix: <commit or doc link>
