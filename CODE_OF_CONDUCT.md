# Code of conduct

Be kind and be useful. Disagree with ideas, not people. No harassment, discrimination, or personal attacks. Assume good intent, give specific feedback, and thank people who take the time to contribute.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, open a private security advisory on the repository (Security tab) or contact the maintainers listed in the repository profile.

This is a short version of the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
